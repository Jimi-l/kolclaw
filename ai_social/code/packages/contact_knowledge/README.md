# contact_knowledge

负责微信 / 企微建联话术、聊天记录结构化和跟进建议。

## 当前实现

- `.codex/skills/outreach-draft/SKILL.md`
- `.codex/agents/outreach-drafting-agent.md`

## 预期输入

- 已确认 shortlist
- campaign summary
- 联系人信息
- 历史聊天记录

## 预期输出

- 建联话术草稿
- 聊天记录结构化摘要
- 待跟进事项

## 说明

该模块目前没有独立的 API、数据目录或知识库实现，包目录已预留，便于后续补充真实建联数据和对话结构化流程。
