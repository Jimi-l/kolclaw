## 1. 账号基础信息表（固定属性）

| 字段名 | 类型 |
|---|---|
| account_id | 文本 |
| platform | 单选 |
| account_type | 单选 |
| verify_status | 单选 |
| register_month | 单选 |
| main_region | 多选 |
| main_language | 单选 |

### 说明

- `account_id`：账号唯一 ID
- `platform`：所属平台
- `account_type`：账号主体类型
- `verify_status`：认证状态
- `register_month`：账号活跃度 / 注册时长相关标签
- `main_region`：运营 / 覆盖地域
- `main_language`：主要语言

### 枚举 / 示例

- `account_id`：`dy_123456`、`xhs_001`
- `platform`：抖音、小红书
- `account_type`：个人号、MCN 机构号
- `verify_status`：未认证、实名认证
- `register_month`：7天、14天、一个月
- `main_region`：全国、省份、海外（国家）、港澳台
- `main_language`：中文、英文、其他
