### 步骤3：自动刷视频（模拟真人养号行为）

**核心策略：模拟真实用户的浏览习惯，通过互动行为培养账号权重，同时避免触发反爬虫机制**

#### 3.1 刷视频节奏控制（V3.3修正 - 极速模式）
```
单视频停留时间：0.5-1秒（仅检测期）
- 非潜力视频：0.5秒 → 立即下滑跳过
- 潜力视频：进入详细分析流程

下滑间隔：0.5-1秒（连续快速刷）
```

#### 3.2 养号策略简化（V3.3修正）
**核心原则**：只对潜力视频执行互动，其他全部快速跳过

| 行为 | 执行条件 |
|------|---------|
| 点赞 | 仅对潜力视频（录入前自动点赞）|
| 其他互动 | 全部取消（评论/收藏/转发不再执行）|

**快速识别优先级**：
1. **广告/直播** → 0.1秒识别 → 立即下滑
2. **数据不足**（点赞<20万）→ 0.5秒识别 → 立即下滑  
3. **潜力视频**（点赞≥20万）→ 进入分析流程

#### 3.3 浏览时段与终止条件
```
单次执行模式（二选一，先到为准）：
- 模式A：连续执行20分钟后自动停止
- 模式B：成功填报10个潜力账号后自动停止

终止后操作：
- 记录本次执行摘要（填报数量、耗时）
- 可选择立即开始新一轮执行，或退出
```

#### 3.4 反爬虫规避策略
1. **鼠标轨迹**：滑动时模拟人类手滑轨迹（非直线匀速）
2. **操作间隔**：每次操作后随机等待0.5-2秒
3. **UA标识**：使用正常浏览器User-Agent
4. **IP稳定**：避免频繁切换IP，保持登录状态
5. **行为分散**：不要固定时间规律操作

### 步骤4：爆款视频识别与数据摘取

#### 4.1 潜力视频判定标准（满足任一条件）
| 指标 | 阈值 | 优先级 |
|------|------|--------|

| 收藏数 | ≥10万 | ⭐⭐⭐ |

**快速跳过规则（非潜力视频）：**
- 广告视频：达人名称后带"广告"字样 → 立即跳过
- 直播间：页面出现"直播中"、"直播间"文字或LiveIcon → 立即跳过
- 普通视频：3秒内快速判定，未达标立即下滑


#### 4.2 爆款视频数据采集（第一步采集）
当识别到潜力视频时，立即提取以下信息：

```yaml
采集字段：
  采集日期: [当前日期，格式：YYYY/MM/DD]
  爆款视频链接: [当前视频完整URL]
  发布时间: [视频发布时间，如：2025-03-28]

  达人名称: [视频发布者昵称]
  粉丝量: [显示的粉丝数，如：12.5万]
```

**爆款时效判定规则（V3.1更新）：**
| 发布时间距离 | 时效值 | 价值评估 |
|-------------|--------|---------|
| 3天内（含3天） | 100% | 🔥极热，趋势初起 |
| 4-5天 | 90% | 🔥高热，仍在传播期 |
| 6-10天 | 80% | 较热，有参考价值 |
| 11-15天 | 70% | 中等，经典案例 |
| 16-30天 | 60% | 一般，长期参考 |
| 30天以上 | 50% | 旧爆款，考古价值 |

**计算示例：**
- 视频发布时间：3月1日
- 采集日期：4月1日
- 距离天数：30天
- 判定：16-30天区间 → **60%**

**采集操作（最短路径 - 零点击提取）：**

1. **获取视频链接（HTML直接提取）**

   - **生成链接**：`https://www.douyin.com/video/{aweme_id}`

   ```javascript
   const match = document.body.innerHTML.match(/aweme_id[=:]\s*["']?(\d+)["']?/);
   const videoId = match ? match[1] : null;
   const videoUrl = `https://www.douyin.com/video/${videoId}`;
   ```

   - 点击视频右侧的**转发数字** → 弹出「转发」弹窗

### 步骤5：账号主页深度分析（标签细化）

**操作指令：**
按 **F 键** 呼出达人缩略主页后，自动进行全面分析：

**⚠️ 关键执行标准（进入详情页后）：**
1. **立即暂停视频**（按空格键），这是最重要的一步！
2. 如果不暂停，视频会按时间倒退自动播放，详情页会滚动到旧视频位置
3. 只有暂停后，才能看到**置顶视频 + 最新发布视频**的正确视野
4. 每次点击视频分析后，**必须暂停该视频**，再返回主页继续分析

#### 5.1 基础信息确认
1. **暂停视频**：按空格键或点击暂停按钮，停止当前视频播放（如未暂停）
2. **确认视野位置**：确保看到的是页面顶部（置顶视频+最新视频）
3. **确认基础信息**：
```yaml
需要确认/补充：
  达人名称: [确认昵称]
  粉丝量: [精确数值，如：125,678]
  获赞数: [主页显示的总获赞数]
```

#### 5.2 推荐流视频位置分析
**观察要点**：
- 在缩略主页中找到**标记为"播放中"**的视频（即当前刷到的推荐视频）
- 观察该视频在主页中的位置：
  - **置顶位置**：视频在顶部，有"置顶"标识 → 达人主动推广的热门视频
  - **中间位置**：视频在置顶之后，按时间排序 → 自然流量爆款
- 记录位置信息，用于流量趋势判断

#### 5.3 流量趋势判定（重要新增）
**目的**：判断达人账号的流量稳定性，评估长期合作价值

**⚠️ 关键前提**：
- 按 **F 键** 呼出达人缩略主页后，详情页会自动播放推荐视频
- 由于推荐视频可能是**旧视频**（如2个月前发布），详情页会自动滚动到该视频位置
- **必须先暂停视频播放**，才能看到**置顶视频 + 最新发布的视频**

**判定方法（修正版）**：
1. **暂停视频播放**：按 **空格键** 或点击暂停按钮，停止当前视频播放
2. **确认视野位置**：确保看到的是**置顶视频**和**最新发布的视频**（页面顶部）
3. **记录推荐视频点赞**：找到标记为"播放中"的视频，记录其点赞数（记为 **推荐视频点赞**）
4. **取最新3条视频**：从**置顶视频之后**（或页面最顶部开始），取**最新发布的连续3条视频**
   - ⚠️ **重要**：不要取"播放中"视频后面的3条（那是更旧的视频）
   - ✅ **正确**：取置顶视频之后、发布时间最新的3条视频
5. **计算平均值**：记录这3条视频的点赞数，计算平均值（记为 **近3条平均点赞**）

**流量趋势判定规则**：
| 判定条件 | 流量趋势 | 说明 |
|---------|---------|------|
| 近3条平均点赞 < 推荐视频点赞 × 1/5 | **昙花一现** | 偶发性爆款，流量不稳定 |
| 近3条平均点赞 < 推荐视频点赞 × 1/2 | **流量波动** | 有爆款能力但波动较大 |
| 近3条平均点赞 ≥ 推荐视频点赞 × 1/2 | **持续爆款** | 流量稳定，持续产出优质内容 |

**示例计算（白昼小熊案例）**：
- 推荐视频（播放中）：保持明亮，熠熠生辉 → **151.2万**
- 最新3条视频（置顶之后）：
  1. 保持明亮，熠熠生辉：153.7万
  2. 开始期待夏天了：84.6万
  3. 再听到她的消息：60.3万
- 近3条平均点赞：(153.7+84.6+60.3)/3 = **99.5万**
- 判定阈值（1/2）：151.2×0.5 = 75.6万
- 99.5万 ≥ 75.6万 → **判定为「持续爆款」**

## ⚠️ 异常处理机制（完全自主模式）

### 1. 登录失效
- **现象**：页面跳转登录页或提示"请登录"
- **处理**：尝试自动重新登录（使用Cookie）→ 若失败则记录问题 → 终止执行 → 向用户汇报需重新登录

### 2. 验证码/人机验证
- **现象**：出现滑块验证、图形验证
- **处理**：记录当前状态 → 尝试绕过或等待5分钟后重试 → 若仍无法解决则终止执行 → 向用户汇报需人工处理

### 3. 数据抓取失败
- **现象**：某字段无法获取
- **处理**：自主决策跳过该字段 → 使用默认值或"未获取"标记 → 记录失败原因 → 继续执行

### 4. 网络异常
- **现象**：页面加载超时、请求失败
- **处理**：等待10秒 → 刷新页面 → 重试3次 → 若仍失败则跳过当前视频 → 记录日志 → 继续执行

### 5. 重复达人
- **现象**：表格中已存在该达人
- **处理**：检查是否为新爆款视频 → 若为新视频则更新视频链接 → 若不是则直接跳过 → 不重复创建记录

### 6. 自主新增标签冲突
- **现象**：新创建的标签与已有标签含义重复
- **处理**：AI自主决策合并至已有标签 → 记录判定标准补充说明 → 继续执行

### 7. 视频播放控制失效
- **现象**：无法暂停视频、页面滚动失控
- **处理**：尝试返回推荐流（按ESC或返回键）→ 若无效则刷新页面 → 从推荐流重新进入 → 记录问题
