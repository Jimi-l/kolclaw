# 【AI智能巡号 - 星图数据补充】执行提示词

## 🎯 任务目标
基于飞书多维表格中已填报的潜力达人数据，自动登录星图平台，查询并补齐达人的星图数据，建立完整的达人资源库。

---

## 📋 执行步骤详解

### 步骤1：登录星图平台

**操作指令：**
1. 打开浏览器，访问 https://www.xingtu.cn/
2. 使用品牌主账号登录（需有查看达人数据权限）
3. 确认登录成功，进入达人搜索页面

**成功判定标准：**
- 页面显示星图平台首页
- 能正常搜索达人
- 有查看达人详情的权限

---

### 步骤2：获取待补齐达人列表

**操作指令：**
1. 打开飞书多维表格：https://my.feishu.cn/base/V1PDbV3kDadIPTsMupYcbkeBnrc
2. 筛选出以下条件的达人：
   - 已有人设标签、内容标签（步骤6已填写）
   - 但**星图id为空**（需要补齐）
3. 按达人名称排序，准备逐个查询

**表格字段映射：**
| 表格字段 | 星图数据位置 |
|---------|-------------|
| 星图id | 达人详情页URL或页面显示 |
| 达人类型 | 星图达人分类标签 |
| 星图主页链接 | 当前页面完整URL |
| 20s星图价 | 报价区域 |
| 20-60s星图价 | 报价区域 |
| 60s+星图价 | 报价区域 |
| 预估播放量 | 数据概览区 |
| 商单播放量中位数 | 历史商单数据 |
| 自然量CPM | 计算或页面显示 |
| CPE | 计算或页面显示 |
| 商单完播率 | 数据概览区 |
| 近15条播放曲线截图 | 截图保存 |
| 月涨粉率 | 粉丝趋势图 |
| 月连接用户粉丝比 | 人群分析区 |
| 月深度用户粉丝比 | 人群分析区 |
| 合作客户 | 历史商单记录 |

---

### 步骤3：逐个查询星图数据

**操作指令：**
对每个待补齐达人执行以下步骤：

1. **搜索达人**
   - 在星图搜索框输入【达人名称】
   - 从搜索结果中确认匹配的达人（核对粉丝量、头像）

2. **进入达人详情页**
   - 点击搜索结果中的达人
   - 等待页面加载完成

3. **提取数据**

| 字段 | 提取位置 | 格式示例 |
|------|---------|---------|
| 星图id | 达人详情页URL中的ID参数 | MS4wLjABAAA... |
| 达人类型 | 页面顶部分类标签 | 颜值/美妆/生活 |
| 星图主页链接 | 当前页面完整URL | https://www.xingtu.cn/... |
| 20s星图价 | 报价卡片 | 5000 |
| 20-60s星图价 | 报价卡片 | 8000 |
| 60s+星图价 | 报价卡片 | 12000 |
| 预估播放量 | 数据概览区 | 50万+ |
| 商单播放量中位数 | 历史商单数据区 | 45万 |
| 自然量CPM | 计算值或显示值 | 15 |
| CPE | 计算值或显示值 | 2.5 |
| 商单完播率 | 数据概览区 | 35% |
| 月涨粉率 | 粉丝趋势图 | 5% |
| 月连接用户粉丝比 | 人群分析区 | 20% |
| 月深度用户粉丝比 | 人群分析区 | 8% |
| 合作客户 | 历史商单记录 | 品牌名称列表 |

4. **截图保存**
   - 近15条播放曲线截图
   - 保存至指定文件夹

---

### 步骤4：数据回填飞书表格

**操作指令：**
将查询到的星图数据，更新到飞书表格对应记录中：

1. 找到该达人的记录行
2. 填写所有星图相关字段
3. 标记状态为"数据完整"

---

### 步骤5：循环执行

**执行策略：**
- 每次查询间隔：5-10秒（避免触发反爬）
- 每查询10个达人：休息1-2分钟
- 单次执行时长：建议30-60分钟
- 每日执行次数：1-2次

---

## ⚠️ 异常处理

### 1. 达人未入驻星图
- 标记为"未入驻星图"
- 跳过该达人，继续下一个

### 2. 数据字段缺失
- 记录实际获取到的数据
- 缺失字段标记为"暂无数据"

### 3. 登录失效
- 重新登录星图账号
- 从断点继续查询

### 4. 搜索无结果
- 核对达人名称拼写
- 尝试搜索昵称关键词
- 仍无结果标记为"星图未找到"
