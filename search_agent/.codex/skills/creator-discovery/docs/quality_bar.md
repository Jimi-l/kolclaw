# creator-discovery / Quality Bar

## 一、总要求

只有满足以下质量门槛的记录，才允许进入 `queued_for_xingtu`。

---

## 二、视频层质量门槛

### 必须满足
- 视频明确达到潜力阈值之一
- 不是广告
- 不是直播间
- 基础互动数据至少能提取出核心部分
- 达人名称清晰可见

### 不合格示例
- 点赞/评论都模糊，看不清
- 视频明显是广告投放内容
- 页面状态异常
- 只因为“感觉像爆款”就进入主页

---

## 三、主页层质量门槛

### 必须满足
- 已确认进入达人主页
- 已暂停当前自动播放视频
- 能定位到当前推荐视频
- 能看到最新内容区域
- 能取出最新 3 条视频数据

### 不合格示例
- 没暂停视频导致页面滚到旧内容区
- 误把“播放中后面的 3 条”当作最新 3 条
- 只看封面不看近期内容就判断流量趋势

---

## 四、流量趋势质量门槛

### 合格要求
- 推荐视频点赞有记录
- 最近 3 条点赞有记录
- 平均值已计算
- 趋势枚举在合法范围内
- 有一句趋势原因说明

### 趋势原因说明示例
- “近期平均点赞显著低于推荐视频，判断为偶发爆款”
- “近期内容连续维持高点赞，判断为持续爆款”

### 不合格示例
- 只有趋势结论，没有依据
- 最近 3 条数据缺 2 条以上
- 平均值与结论明显不匹配

---

## 五、标签层质量门槛

### 人设标签
- 0~2 个
- 必须能从主页、简介、封面或近期内容中找到依据

### 内容标签
- 0~2 个
- 必须反映主内容形式，而非偶发内容

### 场景标签
- 1~3 个核心场景即可
- 不能无限堆叠

### 广告类型
- 单选
- 必须与口播能力、视频时长、内容深度一致

### 不合格示例
- 人设标签 4 个以上
- 内容标签又宽又散
- 场景标签把所有出现过的地点都列上
- 广告类型和内容形式明显冲突

---

## 六、记录层质量门槛

### 最低可入表标准
- `creator_name` 非空
- `video_url` 非空
- `collection_date` 非空
- `total_interaction_text` 非空
- `follower_count_raw` 非空
- `traffic_trend` 非空
- `persona_tags` 已输出
- `content_tags` 已输出
- `ad_fit` 已输出

### 最低可进入 xingtu 标准
除上述外，还需要：
- 达人不是明显重复记录
- notes 中没有严重身份疑点
- `next_action = queue_for_xingtu`

---

## 七、红线

出现以下任一情况，不能进入下游：

1. 达人身份不明确
2. 视频 URL 不稳定或缺失
3. 互动数据无法支撑“潜力视频”判断
4. 最新 3 条判断失败
5. 标签完全靠猜
6. 明显重复未处理

---

## 八、建议的最终检查清单

每输出一条记录前，快速自查：

- [ ] 是潜力视频，不是广告/直播
- [ ] 已拿到视频链接
- [ ] 已拿到达人名称
- [ ] 已拿到粉丝量
- [ ] 已完成推荐视频与最近 3 条对比
- [ ] 已输出流量趋势与原因
- [ ] 人设标签 ≤ 2
- [ ] 内容标签 ≤ 2
- [ ] 广告类型已判断
- [ ] 记录不重复
- [ ] 可以进入下一阶段
