# Xingtu Enrichment Rules

本文件只约束 `xingtu-enrichment`。

## 一、任务目标

对已完成基础筛选的达人，在星图中完成商业字段补齐。

## 二、进入条件

只有满足以下条件的记录才进入本流程：

1. 已有人设标签
2. 已有内容标签
3. `xingtu_id` 为空
4. 当前记录未标记为 `skipped`
5. 当前记录未标记为 `blocked`

## 三、搜索规则

优先使用：

1. 达人名称全称
2. 若无结果，再尝试昵称关键词
3. 搜索后必须通过辅助信息确认是否同一达人：
   - 粉丝量量级
   - 头像
   - 内容方向
   - 标签方向

## 四、匹配规则

### 高置信匹配
以下多数一致时，可判为 `high`：

- 名称高度一致
- 粉丝量量级一致
- 内容方向一致
- 头像/主页风格一致

### 中置信匹配
部分一致但仍可判断时，判为 `medium`

### 低置信匹配
出现以下情况之一则判为 `low`：

- 同名多人
- 粉丝量明显不符
- 内容方向不一致
- 无法确认头像或主页信息

`low` 置信度下，不允许回填价格和商业字段。

## 五、字段提取规则

可提取字段包括：

- 星图 id
- 达人类型
- 星图主页链接
- 20s / 20-60s / 60s+ 价格
- 预估播放量
- 商单播放量中位数
- 自然量 CPM
- CPE
- 商单完播率
- 月涨粉率
- 月连接用户粉丝比
- 月深度用户粉丝比
- 合作客户
- 近 15 条播放曲线截图

若字段不存在，明确放入 `field_missing_list`。

## 六、回填规则

### 允许回填
仅当达人身份已确认时，允许回填：

- 星图 id
- 类型
- 链接
- 价格
- 商业表现字段

### 不允许回填
以下场景不能回填商业字段：

- 搜索无结果
- 同名歧义
- 头像和内容方向对不上
- 页面权限不足导致字段不完整且无法确认达人

## 七、状态规则

根据结果标记：

- `xingtu_completed`
- `xingtu_not_found`
- `xingtu_unregistered`
- `ambiguous_match`
- `field_partial`
- `blocked`

## 八、截图规则

近 15 条播放曲线截图命名建议：

`<date>_<creator_slug>_recent15_curve.png`

例如：

`20260407_baizhouxiaoxiong_recent15_curve.png`

## 九、节奏规则

为避免触发反爬或权限风控：

- 单达人查询之间保留适度间隔
- 连续查多位达人时不要机械匀速操作
- 查询失败不要立即无限重试

## 十、异常处理

### 未入驻星图
- 状态：`xingtu_unregistered`

### 搜索无结果
- 状态：`xingtu_not_found`

### 多个候选无法区分
- 状态：`ambiguous_match`

### 登录失效
- 状态：`blocked`
- 备注：`login_required`

### 页面权限不足
- 状态：`blocked`
- 备注：`permission_denied`
