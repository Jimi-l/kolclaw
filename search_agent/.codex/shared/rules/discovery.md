# Creator Discovery Rules

本文件只约束 `creator-discovery`。

## 一、任务目标

在抖音推荐流中识别潜力达人，并输出基础结构化记录。

## 二、快速跳过规则

以下内容优先跳过：

1. 广告视频
   - 达人名称后带“广告”等明显标识
2. 直播间
   - 出现“直播中”“直播间”等字样
3. 明显数据不达标视频
4. 无法稳定提取达人名称或互动数据的视频

## 三、潜力视频判定阈值

满足任一条件即可进入分析：

- 点赞数 ≥ 20万
- 转发数 ≥ 10万
- 收藏数 ≥ 10万
- 评论数 ≥ 1万

不满足则不进入深度分析。

## 四、主页分析规则

进入达人缩略主页后：

1. 先暂停视频
2. 确保视野回到顶部或最新内容区域
3. 再判断：
   - 推荐视频位置
   - 近期 3 条视频表现
   - 流量趋势
   - 标签

## 五、流量趋势规则

必须按以下逻辑判断：

1. 找到当前“播放中”的推荐视频
2. 记录其点赞数
3. 从置顶之后或最新发布区域取最新 3 条视频
4. 计算最近 3 条平均点赞
5. 用平均值与推荐视频点赞比较

### 输出枚举
- `昙花一现`
- `流量波动`
- `持续爆款`

## 六、标签规则

### 人设标签
- 最多 2 个
- 以核心身份为主
- 优先商业可解释标签

### 内容标签
- 最多 2 个
- 以内容主形式为主
- 优先真正能指导投放判断的标签

### 场景标签
- 1~3 个核心场景即可
- 不要把所有能看到的地点都写进去

### 广告类型
单选：

- `曝光植入型`
- `产品种草型`
- `两者皆可`

## 七、自定义标签规则

只有在系统预设标签明显不够表达时，才允许新增标签。

新增标签时必须同时记录：

- `tag_name`
- `tag_category`
- `reason`

不能只新增名字，不写原因。

## 八、录表规则

进入录表前必须确认：

- 是潜力视频
- 达人名称可识别
- 基础互动数据可识别
- 标签已完成
- 流量趋势已完成

否则不进入正式记录。

## 九、停止条件

自主模式下，满足任一条件即停止：

1. 连续执行满 20 分钟
2. 成功填报 10 个潜力账号

## 十、重复处理

如果发现表格中已存在该达人：

- 若是新爆款视频，可更新视频相关字段
- 若不是新内容，不重复创建

## 十一、异常处理

### 登录失效
- 记录 `blocked`
- 原因写明 `login_required`

### 验证码
- 记录 `blocked`
- 原因写明 `captcha_blocked`

### 数据抓取失败
- 可以跳过单字段
- 但不能伪造替代值

### 页面失控
- 优先返回推荐流重新进入
- 不要在错误页面上继续分析
